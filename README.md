# CA7 Metadata Dependency Intelligence Demo

Public feedback version of the metadata-only CA7 dependency intelligence proof of concept.

## Safety boundary

- Synthetic technical metadata only
- Read-only MCP connector model
- No customer record values
- No production credentials
- No autonomous production operations
- Human review required
